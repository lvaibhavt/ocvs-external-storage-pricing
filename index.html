    How to read the performance rows

    • IOPS / throughput per TiB — the provider's published rate, e.g. OCI Balanced = 60 IOPS per GB (61,440 per TiB), Elastic SAN = 5,000 IOPS per TiB.
    • Maximum for one volume / instance — the most a single volume, SAN, file system or mount target can deliver, however large you make it. This is the "Max IOPS" figure in the OCI cost estimator: an OCI volume stops at 25,000 IOPS on Balanced and 75,000 on Ultra High.
    • Capacity limit for one volume / instance — how big a single volume, file system or instance can be (32 TiB for OCI Block Volume, 64 TiB for an Elastic SAN volume, 192 TiB for an FSx file system).
    • Best split — how many volumes, file systems or instances the capacity is divided into to get the most performance, respecting each service's size and count limits (an OCVS SDDC allows 32 volumes, for example).
    • Total IOPS / throughput — the per-unit maximum multiplied by the number of units, then capped by any service-wide maximum. So 900 TiB on OCI Ultra High is 32 volumes × 75,000 = 2,400,000 IOPS, not 90 IOPS/GB × 921,600 GB.
    • Performance of a 100 GiB volume — what one small volume gets, which is where the per-GB rate matters most.

    Read before quoting these figures

    • Indicative only. Public list prices, no discounts or commitments. Confirm on the provider's own calculator before sharing with a customer.
    • 1 TiB = 1,024 billed units, as in each provider's calculator. OCI and AWS call the unit "GB", Azure and Google "GiB". Check: 1,024 GB OCI Block Volume at Balanced = 1,024 × $0.0425 = $43.52/month.
    • Hours per month (default 730) applies to the per-hour services: Azure NetApp Files, Google Cloud NetApp Volumes and Filestore. OCI, Elastic SAN and FSx quote flat monthly rates.
    • Capacity is provisioned capacity, not capacity after dedupe or compression. Partner products are usually quoted as effective capacity instead.
    • Not included in the price: FSx throughput capacity and extra SSD IOPS, ANF Flexible throughput, Filestore custom performance, OCI HPMT performance units. Each is flagged in the notes.
    • Storage only: no VMware nodes, networking, egress, backup, support or taxes.
