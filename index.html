    How to read the performance rows

    • A datastore is built from several volumes, and each volume has its own IOPS limit. The total is simply those limits added up:
      number of volumes × IOPS each volume gets = total IOPS.
      Example, 100 TiB of OCI Block Volume at Balanced: split into 32 volumes of 3.13 TiB, each capped at 25,000 IOPS, giving 32 × 25,000 = 800,000 IOPS. Split the same 100 TiB into only 4 volumes of 25 TiB and you get 4 × 25,000 = 100,000 IOPS — same capacity, same price, a quarter of the performance. Use the volumes box on each card to try both.
    • The big figure on each card is the maximum for one volume, file system or mount target — the same number the provider's calculator shows (OCI Balanced: 25,000 IOPS). The line under it shows the sum.
    • IOPS / throughput per TiB — the published rate, e.g. OCI Balanced = 60 IOPS per GB (61,440 per TiB), Elastic SAN = 5,000 IOPS per TiB. A volume gets this rate until it hits its maximum.
    • Capacity limit for one volume / instance — how big one volume can be: 32 TiB for OCI Block Volume, 64 TiB for an Elastic SAN volume, 192 TiB for an FSx file system. This sets the fewest volumes you can use.
    • IOPS each one gets — what a single volume of that size delivers, and whether it is at its maximum or below it.
    • Total IOPS / throughput — the multiplication written out, then capped by any service-wide maximum (Elastic SAN stops at 2,000,000 IOPS, for instance).
    • Performance of a 100 GiB volume — what one small volume gets, where the per-GB rate matters most.

    Read before quoting these figures

    • Indicative only. Public list prices, no discounts or commitments. Confirm on the provider's own calculator before sharing with a customer.
    • 1 TiB = 1,024 billed units, as in each provider's calculator. OCI and AWS call the unit "GB", Azure and Google "GiB". Check: 1,024 GB OCI Block Volume at Balanced = 1,024 × $0.0425 = $43.52/month.
    • Hours per month (default 730) applies to the per-hour services: Azure NetApp Files, Google Cloud NetApp Volumes and Filestore. OCI, Elastic SAN and FSx quote flat monthly rates.
    • Capacity is provisioned capacity, not capacity after dedupe or compression. Partner products are usually quoted as effective capacity instead.
    • Not included in the price: FSx throughput capacity and extra SSD IOPS, ANF Flexible throughput, Filestore custom performance, OCI HPMT performance units. Each is flagged in the notes.
    • Storage only: no VMware nodes, networking, egress, backup, support or taxes.
